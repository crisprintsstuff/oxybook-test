# Configure

Pick how you run the server:

<Tabs>
  <TabItem value="compose" label="Docker Compose">
    Set values in `.env`. Compose reads the same file.
  </TabItem>
  <TabItem value="host" label="On the host">
    Load `.env` with `set -a; . ./.env; set +a`, then run `pnpm dev`.
  </TabItem>
</Tabs>

The default port is {3000}. Grafana uses the same port, so set `PORT` when both run.
