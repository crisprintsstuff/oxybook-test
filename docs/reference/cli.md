# CLI

## `oxybook-dev propose`

Opens a pull request for one file.

| Flag                | Required | Meaning                                  |
| ------------------- | -------- | ---------------------------------------- |
| `--remote`          | yes      | Repository URL                           |
| `--github-owner`    | no       | Owner, when a pull request is wanted     |
| `--installation-id` | no       | Or `GITHUB_APP_INSTALLATION_ID`          |
